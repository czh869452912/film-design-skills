# 播放、读图与修正

## 画完整段

按关键状态画出整段，再回头精修。初稿可用缩略图和简笔姿态；需要检查接触时补手与道具，需要检查空间时补地标和脚步。保持目标画幅，用 `S01-P01` 这样的编号连接计划与图片。

同镜内用多格表示姿态、位置或构图变化。绘制深度以当前要解决的问题为准；动作和摄影机都发生变化时，画出有意义的中间状态。箭头可标身体运动、视线或摄影路径，标注版与干净参考图分别保留。

宫格是并排阅读单元，不能代替时间里的观看。保留原 panel 与 shot 归属，多格不自动成为多镜。

## 按实际画面回看

遮住解释性段落，按顺序读图，依赖声音时加入最小声音提示。检查观众能否复述谁做了什么、关键关系如何改变；若有独立读者，先听其复述再解释设计。

同时核对表达：若设计是“接受却不认输”，接受与回避是否实际可见；若是“最后才知道”，前面图像、反射或声音是否提前泄露。能看懂动作，不代表关系与体验已成立。主观反应并不完全一致，记录可追溯的理解和误读，不编造观众共识。

| 失败表现 | 优先检查与修改 |
|---|---|
| 人物或物件突然换位 | 起点、路径与终点；补必要状态或调整调度 |
| 交接或接触不清 | 手、物件支撑与轮廓；重画关键接触格 |
| 图与文字意图不同 | 实际姿态、取景、遮挡与顺序；修改画面 |
| 重要细节看不到 | 画幅内尺寸、视角和注意力；调整调度或切近 |
| 切回后关系断裂 | 切点两侧的动作阶段、地标、视线和朝向 |
| 播放时过快或拖沓 | 表演、信息到达、声音和停留时间；调整格时长或图序 |

修改后连同相邻格重看。生成器执行失败时，针对缺失的关系选局部修图、重画、改变取景或调整执行方式；必要的设计变化同步到计划。

## 定时

从开始保留总时长、台词或音乐约束；初稿允许暂定时间。粗板可读后走戏或播放，调整每格时间和切点。同长、变长或长时间停留由内容决定。

动态分镜是离散图像的定时播放，能检查信息节奏和镜头分组；连续运动还需要足够的姿态或预演支持。切镜时检查动作、视线、空间和注意力怎样传递，声音可提前、延续或改变关系。

先正常速度看完整段，再查关键时刻。必要时比较一个替代切点、停留或声音进入时机；选择基于实际观看差异，不机械套用情绪评分、固定平均镜长或配乐高潮。

已有视频先确认完整文件可读，标出实际可用的入出区间；计划中的动作若被模型重复、回弹或省略，要看发生在何时。只截取可用段可能改变起终关系、台词或总时长，调整后重查相邻镜。静态首尾截图不足以验证其间运动与口型。

## 交付与媒体衔接

交付所需的分镜表、实际图像、时间和声音说明，并记录检验到的层级与具体未解决点。使用体系中的 `shot-design` 工具时按其 `references/shot-list-spec.md` 保存数据；没有该技能也可使用当前编辑工具或直接交付可执行的修订建议。

交给媒体工具时说明素材是用于人物、服装、道具、场地、风格、构图还是首尾状态。参考图序号、镜头号和画格号分别保留；后续状态图不自动成为首帧。按目标工具的当前能力选择参考图，干净裁图用于生成，整页与标注版用于审阅。

方法依据：[Boords animatic](https://boords.com/docs/animatics)、[Toon Boom 的完整粗板与定时讨论](https://www.toonboom.com/tim-hodge-on-storyboarding-for-tv-animation)、Walter Murch 的 *In the Blink of an Eye*（2001）。本方法不使用固定权重判断艺术质量。
