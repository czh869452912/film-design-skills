# 动态预演与回改

让所选画面在时间里成立。可从文字分镜、原画或已有视频进入：文字只能预估，静图可做保持帧预演，真实视频要检查实际运动和声音。已有素材时直接看素材，不要求重新设计全套上游。

## 让时间服务观看

读取创作目标、镜序、原画／素材与必要声音。按动作、对白、辨认与反应分配时间；能同时发生的共用时间，有先后依赖的不能挤在一起。保留总时长与用户要求，不平均切格凑秒数。[播放、读图与修正](references/review.md)

起势、线索出现、反应与收尾是时间里的实际时刻。检查观众何时第一次可能知道，不能只凭末帧正确就判定“最后才知道”。切点与声音可提前或延续，是否采用由表达决定。

有 `shot-design` 工具时可用 `scripts/animatic.py` 和已有分镜 JSON 生成动态分镜；也可使用当前可用编辑器。保持帧不能伪装连续动画，不用平移缩放静图证明真实运镜；正式视频生成可交给 `screen-media`。

## 看结果，再定位问题

先按正常速度看完整段，依赖声音的要回听；再检查关键图与切点两侧。素材可能只在一段区间可用，剪辑取舍需根据实际文件，不能按计划时长猜。

先不给观看者解释性答案，听其描述谁想做什么、发生了什么、何时理解关键关系，再对照目标。没有独立观看者时进行明确的自检，保留不确定性；不把主观感受差异简单计作错误。

定位最早失效处：理解目标错，回导演共创；画框和镜序无依据，回镜头设计；姿态／构图未实现，修原画或媒体执行；图都对但一闪而过，先修时间与声音。改后连同相邻镜重看，保存未受影响的选择，不往全局提示词无限追加规则。

交付所需播放文件或剪辑建议、具体观察与修改、还未解决的内容。分别说明文字、自制粗板、生成图像、实际播放或观众反馈验证到哪一层。技术帧数与文件校验不能证明导演表达质量。
