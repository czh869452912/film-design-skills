# Layout、关键姿态与画面完成度

## 每个机位有共同依据

Layout 放置地面、固定地标、可行路径、人物与道具、摄影机及主要光源。简单场景用清楚的相对关系即可；透视、台阶或接触难以说明时，用平面图、粗线稿或 3D 人偶排演。

世界中的左右、高差、支点与画面投影分开。换机位后画面左右可变，人物不能因此移动；移焦只改清晰平面，不能解除实体遮挡。需要同时读清两人的脸和手时，先检验姿态、距离与取景能否兼得，不能只宣布“全部清楚”。

构图要体现导演选择。明确谁占多少画面、谁在前后、哪一片空区或亮暗负责关系，观众第一眼被什么吸引；不是将人物整齐摆在图中央。光色和媒介在一段中形成整体，位置与动作变化可以改变实际受光，不用统一滤镜抹平所有镜头。

## 图的数量取决于缺什么

Key 是有意义的关键姿态，breakdown 说明动作怎样从一个状态转到另一个状态，不一定是时间中点。单镜可以多张，一张也可以成立；不按视频帧率逐帧生图。

例如验证完整递杯，可先画双方同时支撑同一只杯的关键图，再画递出前与接稳后；手如何靠近、原持有人何时放开仍不明时，补相应转折图。若导演有意省略交接，就按最终方案画，不能以机械动作检查推翻省略。

关键静图写“手已托住杯底、另一只手仍握杯侧”，不写一个完成跨越数秒的动作。另在镜头说明里保留怎样到达／离开和时间关系。动态轨迹、视线箭头与摄影路径保存在标注版，不混入干净视频参考图。

## 参考分别承担职责

| 依据 | 控制什么 | 不应自动控制什么 |
|---|---|---|
| 人物身份／造型图 | 脸、发型、体态或选定服装 | 本镜姿态、机位、背景 |
| 场景／布局图 | 地标、路径、比例、可见空间 | 所有镜头固定同一取景 |
| 风格／光色基准 | 采用的画法、色彩和材质关系 | 人物动作和剧情事件 |
| 姿态／构图草图 | 当前瞬间的身体、道具、遮挡和画框 | 不相关的身份或美术细节 |
| 首帧／末帧 | 指定镜头的起／终画面 | 其他镜头或完整运动过程 |

参考存在与否按实际文件确认；“待生成的人设图”只是计划。每张关键图回到共同基准，减少身份和画风误差层层传递。参考之间冲突时说明当前优先级与损失；不保证模型会准确分离参考职责。

## 绘制路线按可用工具选择

- 已有正确主画面，仅动作局部变化：局部重画、图层合成或支持区域编辑的模型。
- 复杂重心、接触、空间：先摆拍、线稿或 3D 排演，再用支持相应输入的工具整理。
- 只有文生图：从少量最关键画面开始，采用可解释的取景和动作，明确结构控制不足带来的未决处。
- 有多图参考或结构条件：分别提供身份、布局和姿态；确认接口实际支持及输入含义，骨架本身不保证手与物接触。

这些是路线选择，不是成功率承诺。核心画面不能成立时，先解决它，不为了完整张数扩出整段。

## 读图与交付

打开实际原图，检查关系、取景和信息显露；缩小看轮廓，必要时放大接触，再叠看相邻姿态的体积、支点和路径。不要只看局部漂亮而漏掉整段关系。

宫格由已选图片排版时，保留每张图原始 ID 和切镜归属。若直接生成整页，先核对真实格数与边界；格数不符不能硬裁成计划格数。排版检查和内容认可分开，失败图也可以排版用于诊断。

方法依据：[Disney Layout](https://www.disneyanimation.com/process/layout/)、[Toon Boom layout/posing](https://learn.toonboom.com/modules/layout-cleanup/topic/what-is-layout-posing?c=34)、[marked drawings](https://learn.toonboom.com/modules/layout-and-posing/topic/about-marked-drawings?c=34)、[Blender onion skinning](https://docs.blender.org/manual/en/5.1/grease_pencil/properties/onion_skinning.html)。这些方法不等于已验证某个生成模型能执行。
