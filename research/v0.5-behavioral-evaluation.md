# v0.5 行为评测：先检查基础分镜

这套题用于下一轮真实执行和盲读。它不是已完成的效果证明。当前已完成结构/媒体回归；案例文字推演由改造执行者编写，不能算独立验证。

## 执行方法

给执行者新用户简报和技能，不给本页观察项或参考答案。保存初稿、实际粗图、修改稿；若没有出图条件，标记为文字层，不能评视觉层。对照版本用同一简报、素材、资源预算与时限，匿名随机排序。

评审者先只看画面序列及必要声音提示，复述谁做了什么、关键关系怎么变；再看文字，区分画面成立与解释成立。记录具体误读位置和回改是否修复，不给术语数量、表格齐全、JSON 使用、机制引用加分。

## 八类任务

| 任务简报 | 可观察的基础能力 | 不能靠什么冒充通过 |
|---|---|---|
| 甲从桌上递杯给犹豫的乙；乙接过。无反转，无指定镜数 | 取杯、靠近、接触、承托、松手可追踪；犹豫有可见行为 | “释怀”“动作连续”等注释 |
| 两人在台阶一次交锋，甲躲过乙，乙收住。10 秒，无血浆 | 起点、路径、避让时机和终点可对应；武器所属清楚 | 藏在切点的瞬移、凭空碰撞声 |
| 甲等一个没来的朋友，手机亮起，甲不看。无对白 | 等待、手机与拒看之间的观看组织；表演可读 | 强行补来电内容、哭泣或反转 |
| 四件器物，每件两秒，同等比较，无故事冲突 | 保留等时长与展示目标 | 为避免均分而改时长、强加高潮 |
| 一镜拍小孩发现桌下猫，蹲下招呼，猫退后 | 单镜多状态、视线和遮挡变化；不擅自切镜 | 一个首帧加一段动作长注释 |
| 三个人在小厨房交接托盘，指定人物身份和入口 | 人、手、托盘路径和必要遮挡可追踪 | 只写“不越轴、保持连续” |
| 提供粗板：杯在甲手中，下一格却在远处乙手中 | 找到缺失的转移证据，选择补过程或明确省略依据 | 只润色镜头语言或添加负面词 |
| 只要求一段竖幅双人对话的文字分镜，模型未定 | 按画幅调度、人物反应与关系；交付规模合适 | 禁止竖幅双人、默认 H3、先输出整套 JSON |

## 记录方式

每例记录：输入约束是否保留；关键行动是否完整或合理省略；人物/物件能否追踪；观看先后是否支持理解；发生了什么具体回改；实际检验到了文字、图片还是播放哪一层。

失败项记“画格/切点 + 读者误读 + 画面证据 + 修改”。通过项也写读者实际复述，不以作者自述意图代替。没有独立读者或实际画图时，明确写未验证。

工具边界另测：错误编号/引用/时长/缺图应报错；文字中的物理冲突即使通过结构校验，也不能显示质量满分。后者当前已通过工具回归，前八类的创作效果仍待实际测试。
