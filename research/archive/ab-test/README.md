# A/B 测试说明

目的：验证 `shot-design` 技能是否真的改善镜头设计，而不只是改变了输出格式。

## 设计

- 2 份简报（A 情绪向 12 s；B 动作向 10 s）× 2 条件（无技能基线 / 使用技能）。
- 4 个子代理独立完成，互不可见；基线代理被明确禁止读取技能文件。
- 输出匿名化为 X / Y 交给独立评委盲评，评分维度见 `judge/rubric.md`。
- 机械指标另行统计：镜数、时长分配、每镜字段完整度、技能侧脚本校验结果。

## 已知混杂因素

- 同一模型、不同随机性：两份输出都可能偏好或偏坏，1 份简报只能提供方向性证据。
- 技能侧被要求输出 JSON 并自检，天然会更结构化；评委被明确告知"不要因格式加分"。
- 基线代理不知道会被结构化比较，可能写得更短。

## 图像环节

NovelAI 同一时间只允许一个请求，因此两格分镜按顺序生成（先 X 后 Y），使用同一段模板提示词，只替换该侧自己的第 1 镜画面描述，用于检验"设计是否可绘制"。
