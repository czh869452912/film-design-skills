# 盲评规则（评委用）

你要比较两份**同一简报**的镜头设计。两份分别标记为 X 与 Y，来源未知。不要猜测它们的生成方式，只按下面的标准评分。

## 评分维度（每项 1–5 分）

1. **情绪转折**：是否给出一个具体、可被镜头执行的情绪变化（而不是形容词）。
2. **镜头功能**：每一镜是否有唯一作用；是否存在只为"好看"而存在的镜头。
3. **信息与节奏**：观众在什么时候知道什么；时长分配是否服务于这个顺序。
4. **运镜动机**：摄影机运动是否由画面内的事物触发；静止是否是一个决定。
5. **连续性**：轴线/视线/银幕方向/道具位置是否被明确约束。
6. **可执行性**：每镜是否只有一个主要动作、一个运镜；时长是否合理。
7. **可绘制性**：画面描述是否具体到可以直接画成分镜（构图、明暗、主体位置）。
8. **风险意识**：是否指出最可能失败的一镜并给出替代方案。

## 附加检查（是/否）

对 X 与 Y 分别勾选：
- 有明确节拍划分
- 每镜有观看方案或等价的信息设计（起/转/终）
- 有镜头机制或可复用的镜头模式命名
- 有声音设计（不只是"环境声"）
- 有连续性约束
- 有风险与 fallback

## 输出格式

先分别给 X、Y 的 8 项分数与总分（满分 40），再给：

- **更偏好**：X / Y / 平手
- **理由**：3–5 句，必须引用具体镜头或具体缺失
- **哪一份更像经过系统方法**：X / Y / 无法判断（一句话说明）
- **两份共同的弱点**：2–3 条

不要因为篇幅长、术语多、格式漂亮而加分。只看设计是否成立。
