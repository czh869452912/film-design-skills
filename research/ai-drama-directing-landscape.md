# AI 短剧／漫剧工具与导演能力：可以吸收什么

调研日期：2026-10-25。范围是公开 skill 源码、应用的提示词／工具实现、官方产品文档及相关论文。开源项目固定到文末提交；没有安装这些应用、运行其生成链或独立复现论文结果。本报告提出的改造与评测尚未执行。

## 判断

这个 repo 值得聚焦的方向是：**把人的复杂创作意图，逐步变成十五秒以内可观看、可修改的视听设计。** 长篇小说改编、批量出片和供应商接入可以借用现有工具。

但“社区没有从影视理论汲取导演能力”说得太满。本次读到的 `ai-film-skills`、`drama-skills`、Toonflow 和 `visual-skills` 都包含实质的调度、表演或观看方法。有的内容比本 repo 当前精简版更深入。真正需要验证的，是这些方法能否持续改变拍法，并在实际画面、时间和声音中保留下来。

因此不宜用“引用了传统书籍”作为差异点，也不宜用更多字段、检查器或名为 Director 的 Agent 证明导演能力。应以具体场景回答：理解了人的哪层意思，为什么这样拍，实际观众看到了什么，修改一句意图后哪些地方会跟着改变。

早期归档清单中“没人把镜头方法做成可校验数据和 animatic”的判断缺乏足够证据，不作为本轮结论。

## 2. 研究系统提供的启发

不需要为了借用这些思想就在本 repo 加多 Agent。

- **FilmAgent** 把演员站位、动作和摄影机放进可执行的 Unity 空间，并通过反馈修正方案。值得借的是让镜头有一个共同世界可供验证。其动作、站位和镜头库是预配置的，不能据此推断能处理任意细腻表演或自由打斗。[论文 §3.1–3.4](https://arxiv.org/html/2501.12909v1)
- **Camera Artist** 显式利用前镜上下文规划后镜，再加入摄影表达。值得借的是相邻镜共同设计，避免各镜独立重写。摄影描述丰富或序列连贯，仍不足以证明复杂潜台词被观众读懂。[论文 §II](https://arxiv.org/html/2604.09195v1)
- **SkillPE** 从匹配、弱匹配和有启发的近似案例中，修正技法的适用条件并探索变体，再评估生成视频。对本 repo 的启发是把模板改成带适用条件、失败边界和反例的案例，而非不断添加配方。论文也报告了创造性与意图忠实度的取舍；其结果不能直接外推到当前 NovelAI 路径。[论文 §3、§4](https://arxiv.org/html/2609.34335v1)

这些工作说明导演设计并非无人研究。我们的实际机会在于把它做成短片段中可用、可改、可验证的协作能力。

## 3. 怎样把书中的经验变成能力

首先要保留书里“通过制作发现方案”的部分。Katz 在 *Shot by Shot* 第 1 章讨论的可视化，不只是把脑中完整成品抄出来；画、排列、回看和修改本身会让目标变得清楚。本机已有提取文本 `build/extracted/shotbyshot_p001-160/full.md`（不发布书籍及 OCR），相关内容在 `Visualization` 一节。不要把人的第一句话过早冻结成不可更改的摄影规格。

Disney 的 layout 流程同样把人物、布景、道具、机位和粗动画放在一起迭代，并重新判断视点、取景及镜头增删。对于十五秒的段落，这支持一条紧凑的路径：先有足以比较观看效果的粗图／排演，再逐渐提高原画精度。[Disney Layout](https://www.disneyanimation.com/process/layout/)

下面是对本 repo 的转化建议，不是声称作者提出了这些软件规则：

| 理论来源 | 在短片段中应体现的判断 | 应留下的证据 |
|---|---|---|
| Katz：可视化、调度、摄影与连续性 | 同一行动怎样被不同机位和镜序理解；粗图暴露的问题怎样改变方案 | 少量实质不同的缩略图、必要平面图、所选拍法及取舍 |
| *Framed Ink*：画面与图序的视觉叙事 | 观众先注意哪里；轮廓、空区、明暗和前后景是否让关系成立 | 缩小后仍可读的画面；相邻画格的注意力变化 |
| Bruce Block：视觉结构 | 空间、明暗、色彩、运动等关系怎样随片段变化 | 同一段起点与结尾的实际视觉差异，而非每镜相同风格词 |
| Murch：剪接取舍 | 为什么在此切、为何留在此处；信息、表演、节奏和连续性冲突时保什么 | 有声音和停留的播放版本；必要时比较一个替代切点 |

*Framed Ink* 的出版方也明确将单画面构图、连续镜头及人物姿态列为内容；不能把它缩成静态构图模板。[出版方说明](https://designstudiopress.com/products/framed-ink)

具体做法可以很轻：检索一个相关问题，采用或改写其中的机制，在粗图里比较。轴线、景别、焦距和运镜是设计变量；不要求把它们逐项展示给人填写。Murch 的比例尤其不宜直接成为自动评分权重。

## 4. “转换复杂意图”具体转换什么

人的输入可能同时包含故事事实、关系潜台词、观看体验、造型参考、运动想象和制作限制。这些需要拆开理解，但不必要求人先学会术语或填写六张表。

例如“镜头像迟疑着不敢靠近”可能指观察距离始终受阻，也可能指跟进比人物动作晚半拍；“两人仍像隔着一堵墙”可能是调度与构图关系，不一定要求添加实体墙。先结合上下文提出一个具体可看见的解释；只有会实质改变表达时才比较另一种解释。摄影机运动、人物运动、播放变速和剪辑也要分开，避免把人的运动想象翻译错。

建议保留一条简短的决策链：

> 人的意图与开放项 → 观众逐步经历什么 → 人物如何行动、声音如何出现 → 从哪里看、何时切或不切 → layout／关键姿态 → 生成与播放后的反馈

这是一条可回改的关系，不是必须一次走完的审批流水线。人可以从参考片、已有原画、单句感受或失败画面进入；后续修改也应回到相应决定。

### 一个十二秒以内的例子

假设输入是：“甲把杯子递给乙。乙接了。想表现乙接受好意，却不愿显得先让步；不要煽情。”

这里新增的创作开放项是观看方式与表演细节；交接成功是既定事实，不新增争吵、解释对白或和解微笑。两种候选可以这样比较：

| 拍法 | 画面如何成立 | 观众获得／失去什么 |
|---|---|---|
| 留在双人同框 | 选择能读清头部与手的侧面构图。乙避开对视却接稳杯子；甲在确认支撑后松手。停顿留在两人之间 | 连续地看到接受和回避同时发生，保留尴尬与距离；细微表情可能不如近景明确 |
| 延后让观众看见接受 | 先看乙保持疏离的脸，交接发生在取景外；最后切手部，杯子已经稳在乙手中 | 前一刻的拒绝印象被重新理解；交接过程被省略，不适用于用户要求全过程可见的版本 |

两者改变的是观众的信息先后和人物关系的呈现。仅把中景换成 85mm、加“克制、电影感”，没有完成这一转换。

用户选择后，才细化必要原画。第一种可能需要“伸出、共同承托、松手、接稳后仍不对视”等状态；第二种不必为了证明机械过程补回被有意省略的画格。画格数量服从拍法。

绘制后检查两个问题：杯子交接在动作上是否成立；“接受但不认输”的关系是否有可见依据。前者是基础可读性，后者才触及这里的导演目标；任何一项都不能只凭提示词判定通过。

## 5. 对当前 repo 的具体取舍

当前 `references/design.md` 已包含信息先后、同框／切近、表演与空间选择，主线方向可保留。问题是这些方法尚未得到足够的导演表达测试；现有递杯、避让、小孩／猫实验主要暴露了绘制与空间执行问题。精简文件本身也不能证明模型会深入采用这些方法。

建议保持三种职责，直接利用现有文件，不增加一套同义模块：

1. **设计：** 在 `design.md` 中用少量完整案例展示“意图—候选—取舍—画面”的关系。比再增加术语定义更有价值。保留有意遮蔽、省略、不断镜、静止与强烈摄影的选择空间。
2. **预演与绘制：** 延续[上一份原画调研](key-animation-workflow.md)的共享 layout、关键姿态与必要转折帧。关键原画是导演选择的视觉承载，也可以反过来修正选择；画得精美不能补偿观看顺序错误。
3. **执行与反馈：** `pageboard.py`、图片适配器和 `animatic.py` 承接已经选择的方案。模型做不到时说明具体损失，提出替代并保留原意；不悄悄用供应商时长或独立生成的接缝规则重写拍法。

### 优先吸收的工具设计

- **同一内容的多种视图。** 简明分镜表看职责，宫格比较画面，时间线看实际显露与停留。宫格继续有用，但不意味着必须一次让模型画出整页。
- **参考素材分别负责什么。** 同一张人物图可管身份，不自动控制姿态和构图；场景图可管地理，不自动冻结摄影机。先复用现有资产路径与 ID，不新造完整资产管理平台。
- **按意图局部修改。** “保留表演，改成最后才让观众知道乙接了杯子”应修改取景、镜序和相应原画；角色外观与场景无需重做。“手接触错了”优先修姿态和图像。
- **记录失败发生在哪里。** 意图理解错、拍法没有支撑意图、图像没执行拍法、定时让线索来不及被看见，分别处理。避免每次失败都往全局提示词追加一条禁止事项。

### 暂不吸收的设计

不新增小说到成片的全链、多 Agent 剧组、固定起承转合镜数、每镜细节配额或普遍情绪—角度映射。不把一个段落最多十五秒，解释成每段必须用满十五秒或必须若干镜头。复杂性应来自这场戏的实际需要。

## 6. 如何证明改造有效

接下来应同时测试“能否设计出区别”和“画面能否实现区别”，避免继续只统计生成成功、角色相似和字段合法。

| 待测任务 | 主要观察 |
|---|---|
| 相同递杯事实，分别表达疏离、试探、默契 | 行动、取景、停留或声音是否产生实质差异；有没有偷偷增删故事来凑效果 |
| 同一揭示，分别让观众先知、同步发现、后知 | 图像与播放中首次可见／可听的时刻是否正确 |
| 一段十五秒内的对白，保持台词，改变听者承担的后果 | 切点与反应是否跟随关系变化，而非逐句正反打 |
| 同一事件比较连续同框与切分版本 | 能否说明同时性、细节、空间或等待感的具体损益；是否实际成立 |
| 人提出局部修改：“更疏远，别靠改表情” | 是否能通过距离、遮挡、取景或停留解决，同时保存锁定事实 |
| 一张效果漂亮但误导关系的图，与一张清楚的粗图比较 | 是否会因美术完成度误判导演表达；两者问题分别是什么 |

先完成少量文字／缩略图对照，淘汰只有形容词差别的方案；再选一题做受控绘制。共享人物与场景，分别记录设计、绘制和定时的结果，避免把不同出图质量误当成导演差异。

观看评审先不给意图答案，也不给解释性字幕：让观看者描述“谁想做什么、关系怎样、何时明白了什么”，之后再对照创作目标。主观感受允许不同；重点是出现了哪些可追溯的理解、误读和线索。已有观众选择当然可以参与最终取舍，不把作者自评称为盲评。
