# v0.7 收敛整理

日期：2026-10-25。目标是明确当前用法，减少重复与历史规则干扰；本轮没有新增生成实验或创作效果结论。

## 问题与处理

| 累积问题 | 处理 |
|---|---|
| 动作、观看、构图、情绪分别成文，却反复解释相同决策 | 合为 `design.md`，围绕当前画面要解决的问题组织 |
| 粗板、回看、剪接、交接重复讲边界与失败修复 | 合为 `storyboard.md`，串起画图、回改、定时与交付 |
| 入口、README、参考资料反复否定旧版本的配方 | 入口只讲当前主线，修改历史归档 |
| 机制先有 42 行索引，再有 42 行细表和固定搭配 | 合为一份解法表，稳定 ID 保留，按需查阅 |
| 旧镜头卡与当前简明示例并列 | 当前示例留三份，旧卡移到兼容测试数据 |
| 实验、提案、一次性迁移脚本像在用的生产组件 | 归入研究档案；当前辅助工具单独说明 |
| `eval.py` 名称容易暗示效果评测 | 更名为 `inventory.py`，保留结构和语料统计职责 |

## 当前内容归属

`shot-design/` 是可安装产物，入口只有一条主线：事件与观看 → 完整粗板 → 读图回改、定时交付。

| 唯一维护位置 | 内容 |
|---|---|
| `SKILL.md` | 工作主线、三个单位、按需入口 |
| `references/design.md` | 动作与空间、观看选择、取景和构图 |
| `references/storyboard.md` | 粗板、读图回改、定时和媒体交接 |
| `references/novelai-pages.md` | 整页提示、逐次出场、坐标、编译与裁图格式 |
| `references/shot-list-spec.md` | JSON、文件、命令与兼容约定 |
| `references/worked-examples.md` | 递杯、侧让、等时长展示的候选推演 |
| `references/templates.md` / `sources.md` | 解法索引／来源 |

根 README 负责仓库导航，研究目录负责证据与历史。`research/archive/` 收纳早期实验和流程草案；`tests/fixtures/legacy/` 保存旧格式回归数据。归档保留原记录，旧命令中的路径可能是归档前位置。
