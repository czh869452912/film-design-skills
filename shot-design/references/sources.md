# 方法来源

下列资料用于设计方法和模型字段；具体样本能否读懂，以实际绘制和播放记录为准。第三方署名与许可说明见 [NOTICE](../NOTICE)。

## 分镜与观看

| 资料 | 对应主题 |
|---|---|
| Steven D. Katz, *Film Directing: Shot by Shot*, 1991 | 可视化、调度、取景、运动与连续性；ch.3–7、9、13–20 |
| Marcos Mateu-Mestre, *Framed Ink*, 2010 | 构图、明暗、空间与图序；不同版本页码可能不同 |
| Bruce Block, *The Visual Story*, 3rd ed., 2020 | 空间、线条、形状、明暗、色彩与运动的关系 |
| Walter Murch, *In the Blink of an Eye*, 2nd ed., 2001 | 情绪、故事、节奏、视线与空间的剪接取舍 |

- [Disney Animation — Story](https://www.disneyanimation.com/process/story/) 与 [Layout](https://www.disneyanimation.com/process/layout/)：粗图探索、调度、场景和摄影协同调整。
- [Pixar in a Box — Storytelling](https://www.khanacademy.org/computing/pixar/storytelling)：视觉叙事、反馈与修改。
- [Toon Boom — Tim Hodge](https://www.toonboom.com/tim-hodge-on-storyboarding-for-tv-animation)：完整粗板、细化与定时。
- [Magliano & Zacks — Continuity editing](https://pmc.ncbi.nlm.nih.gov/articles/PMC3208769/)：动作连续性与事件理解。

资料用于设计变量与取舍，不是情绪—机位的固定映射，也不证明具体生成模型能够执行。媒体适配与实验记录不作为镜头设计的通用法则。
