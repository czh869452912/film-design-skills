# 镜头解法索引

动作和观看问题明确后，按需选用。ID 用于检索和旧数据兼容；表中的解法需要在当前场景里检验。

| ID | 名称 | 可尝试的解法 | 回看重点 |
|---|---|---|---|
| M01 | Space omen | 环境先变化，再让来者进入 | 预兆能否被注意到 |
| M02 | Descent | 跟随主体下落并交代落点 | 身体与地面的关系 |
| M03 | Orbit reveal | 绕主体逐步看见不同侧面 | 绕行揭示了什么 |
| M04 | Dead stop | 运动前后保留静止 | 停顿里是否有可读变化 |
| M05 | Wind-up | 显示重心、蓄力与意图 | 准备姿态是否清楚 |
| M06 | Dash | 用身体与环境的相对运动表达接近 | 距离与速度能否判断 |
| M07 | Impact close | 切近关键接触点 | 接触双方、所属与后果 |
| M08 | Hit-and-fly | 跟随被撞后的运动 | 起因与运动是否接续 |
| M09 | Shockwave | 用环境响应表现冲击 | 波及方向与空间逻辑 |
| M10 | Landing | 保留触地、压缩与收稳 | 身体怎样停止 |
| M11 | Aerial chase | 以距离、大小和遮挡组织空中追逐 | 前后位置是否可辨 |
| M12 | Track-through | 跟随主体穿过场地 | 地标与路线能否连贯 |
| M13 | Standoff | 同框或相对视角保留对峙 | 距离和关系是否清楚 |
| M14 | Power compare | 用空间、占幅和表演比较双方 | 比较是否符合情境 |
| M15 | Eye-line cut | 通过视线连接主体与目标 | 看向谁、看见什么 |
| M16 | Turn | 让转头或转身带出发现 | 转向与目标的时机 |
| M17 | Interrupt | 让新主体打断既有行动 | 观众能否定位进入者 |
| M18 | Reaction insert | 给反应独立观看时间 | 反应与触发事件的关系 |
| M19 | Detail insert | 用小物件承载关键变化 | 尺寸、所属和前后状态 |
| M20 | Reveal flip | 新信息重新解释当前画面 | 揭示的先后与落点 |
| M21 | Pull-out landing | 拉开后保留新的空间关系 | 主体是否仍有观看价值 |
| M22 | Doorway frame | 借门、窗或前景组织观察 | 遮挡与观看立场 |
| M23 | Shot / reverse | 在交谈双方间分配视角 | 视线、反应与切换理由 |
| M24 | Master two-shot | 同框表现人物相互影响 | 行动和反应能否同时读到 |
| M25 | OTS power shift | 以过肩和占幅变化调整关系 | 前景肩膀与表演遮挡 |
| M26 | Walk and talk | 用行走调度承载对话 | 信息、步速与环境变化 |
| M27 | A-pattern block | 将三人组织在可读的平面关系中 | 注意力在三人间的传递 |
| M28 | L-pattern block | 用纵深错开群体 | 遮挡、朝向与视线 |
| M29 | Insert bridge | 用细节或反应连接前后观看 | 回到主空间后关系能否认出 |
| M30 | Silent two-shot | 留在同框里观察未说出口的反应 | 目光、距离与动作变化 |
| M31 | Lone figure | 用人物与周围空间形成关系 | 孤立感是否来自具体语境 |
| M32 | Push to face | 靠近并集中观看表演 | 接近时机与表情变化 |
| M33 | Crowd swell | 用群体反应呈现事件波及 | 人群反应的起因与传播 |
| M34 | Vehicle approach | 通过环境与主体关系表现到达 | 路线、尺度与停点 |
| M35 | Parallel pair | 交替两处相关行动 | 时间与关联能否被理解 |
| M36 | Dream drift | 让漂移形成连续的主观体验 | 变化是否服务预期感受 |
| M37 | Comedy hold | 在动作或笑点后继续停留 | 期待如何被延长或改变 |
| M38 | Reaction chain | 让反应在多个主体间传递 | 顺序与差异是否有意义 |
