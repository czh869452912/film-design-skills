# 动作、观看与取景

用于解决“发生什么、观众如何看清”的问题。先写可表演的行动，再用粗图比较需要的视角。

## 事件与空间

用普通动词连接起始状态、行动、应对和结果。对话要看人物想得到什么、何时看向对方、停顿或改变距离；展示与氛围段落按其观看目标组织。重要变化需要可见或可听的证据，例如“把第二只杯子放到对方身前”比“关系缓和”更便于绘制。

涉及交接、接触或避让时，追踪人物和物件在相邻状态中的位置、支撑与朝向。递杯的关键是乙接稳后甲松手；侧让的关键是身体何时离开刀路、刀经过哪里、双方停在哪里。只在这些关系需要澄清时画小平面图，标人物、地标、层高和摄影机。

世界方向与画面方向分开记录：同一条向东的路径，换机位后可能向画左、画右或朝镜头移动。省略动作时，前后画面应给观众足够的推断依据。

## 观看选择

确定当前必须看见什么、由谁先知道、何时揭示，以及声音或画外空间承担什么。

| 选择 | 能带来的观看价值 | 需要检查 |
|---|---|---|
| 同框保留行动与反应 | 同时性、距离和相互影响 | 手部或表情是否太小 |
| 切近或切反应 | 强调细节、分配注意力与时间 | 所属关系、动作阶段能否接上 |
| 运镜跟随或揭示 | 在连续时间中改变信息和空间关系 | 路径、遮挡、到达时机 |
| 声音或画外行动 | 提前提示、延后揭示、保留未知 | 歧义是否符合本段目的 |

有实质分歧时画少量缩略图比较。每个新视角都应有观看理由；相同构图也可以靠表演变化持续成立。情绪结合行为、语境、时间和声音设计，机位高低本身不能保证情绪。

## 取景与画面组织

| 景别 | 适合观察 | 容易失去的信息 |
|---|---|---|
| 远景 WS / EWS | 环境、路径、群体关系 | 手部与微小表情 |
| 全景 FS | 身体重心、脚步、完整表演 | 小道具细节 |
| 中景 MS / MCU | 人际距离、上身动作与表情 | 脚步或接触点 |
| 近景 CU / ECU | 表情、手和物件细节 | 空间与所属关系 |

将必要的人物、物件和动作放进目标画幅，再用轮廓、负空间、前后景、明暗、色彩与视线组织注意力。缩小粗图检查关键接触点是否仍可辨认；跨格检查眼睛能否及时找到下一处变化。

每个重要镜头具体设计起点、关键变化和终点的画框：什么占主画面、在框内多大、怎样被遮住或显露、空区与明暗重量如何变化。空间方向清楚只是基础；继续让画面关系表达人物距离、压力或所选视觉体验，不靠给取景加“电影感”完成设计。

共同排演人物、摄影机和光源。靠近镜头会改变主体尺度，主体与相机同速同行不会自动推近；人物进入不同受光区会改变亮暗，反打不会搬动世界光源。光色、透视与材质在图上检验，不用一组毫米数和色温替代可见结果。

摄影机位置决定透视；同一位置换焦距主要改变取景范围。需要保持主体大小而移动摄影机时，空间关系也会改变。毫米数还依赖画幅，具体效果以粗图确认。

固定机位依靠画内变化；pan/tilt 改变朝向；track/dolly 改变观察位置；orbit 改变绕主体的关系；zoom 改变取景范围。连续镜头可组合运动，用关键构图状态检查路径和信息到达时机。

复合运动排出起始画框、触发、经过时看见什么、转向／遮挡／焦点接力、终点及停留。人物行动、摄影机、播放速度和剪辑分别说明；“快切”不等于人动作变快，“世界倾倒”不等于摄影机滚转。形式复杂度不证明表现力，有效的大胆摄影也不应被一律简化成固定中景。
