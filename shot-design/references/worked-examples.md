# 分镜推演

以下是候选设计，配套 JSON 中的时间用于工具演示。实际生成结果属于实验记录，应另行读图验收。

## 递杯：一镜四格

输入：甲把桌上的杯子递给犹豫的乙，乙最后接过。选择桌前固定双人中景，甲左乙右，双手与杯底可见。

只有“甲递杯 → 乙接过”会漏掉承托变化。粗板按关键状态补齐：

| 画格 | 可见状态 |
|---|---|
| S01-P01 | 杯在桌面，甲握杯；乙看杯，双手仍在自己一侧 |
| S01-P02 | 甲提杯递近，乙的手从杯底下方靠近，仍有间隙 |
| S01-P03 | 乙托杯底并扶住杯侧，甲仍握着同一只杯 |
| S01-P04 | 甲松手收回，乙独自持杯并抬眼 |

犹豫通过目光、伸手与停顿表现。若 P03 看不清，先调整手的来向、距离或取景，再决定是否切近。若 P03 已变成乙独持，说明交接状态仍缺失。

数据：[cup-handoff.json](../examples/cup-handoff.json)，1 镜、4 格、暂定 6 秒。

## 神社侧让：三镜八格

输入：黄昏石阶，B 先动，A 侧让一次，B 收住后回看；10 秒，无对白、配乐、慢动作或血浆。A 的刀始终在鞘内，B 使用出鞘刀。

A 起初在上层宽平台，B 在下方两级。B 上到平台斩击；A 在刀到达前向平台侧面让一步，保持同一高度；刀经过 A 原位置，B 在附近收住。双方最终仍在平台上。用 +Y 标上阶、+X 标侧移，摄影机均在 +X 一侧观察。

| 镜头 | 画格与观看内容 |
|---|---|
| S01：较远全景 | P01 建立距离、层高与刀的状态；P02 B 前移重心 |
| S02：同侧较近全景 | P01 B 到平台边缘；P02 斩击开始、A 侧让；P03 A 已离开刀路、刀经过空位；P04 B 收住降刀 |
| S03：回较远全景 | P01 确认双方同层且侧向错开；P02 B 转头找 A，A 未追击 |

关键是 S02-P02/P03 的时间与空间：必须能看见 A 如何离开刀路，脚、刀与身体轮廓分开。较近机位若容纳不下，就保留全景或改两镜。S03 要能与 P04 对上最终位置。声音仅跟随实际动作，无武器接触就没有金属撞击。

数据：[duel-basic.json](../examples/duel-basic.json)，3 镜、8 格、暂定 10 秒。

## 器物展示：四件等时长

输入：四件器物，每件两秒，同等比较。每镜展示一件，使用可比的取景、光线与观看时间；画格只需覆盖各镜有意义的变化。

本例检验是否保留展示目的和同等时间。数据：[display-montage.json](../examples/display-montage.json)，4 镜、每镜 2 秒。

## 接杯但不让步：画框保住潜台词

输入：交接成功，但乙不愿显得先让步，不加对白与微笑。选同框呈现手已接受、脸仍回避；不是把第一例的结果“乙抬眼”直接沿用。

| 画格 | 画框、表演与观看 |
|---|---|
| S01-P01 | 斜侧双人中景，双方分占两侧，头和桌边手在框内；乙看向画外，甲持杯 |
| S01-P02 | 同一取景，杯进入两人之间的空区；乙从自己的位置伸手托住，脸不转回；接触处不被前臂挡住 |
| S01-P03 | 甲松手、空手退回，乙接稳；摄影机不跟手推近，仍看见两人的距离 |
| S01-P04 | 杯收在乙自己一侧，两人身体不靠近；停留让“接受”与“距离仍在”同时可读 |

候选暂定 1.5／2.5／1.5／2.5 秒，总八秒；必须走戏与绘图再定。手脸若过小或互相遮挡，应先试机位和距离；需要切近时说明会损失哪一部分同时性。若改为末尾才揭示接杯，就要重新设计镜序，不能在上述同框里先泄露再声称后知。
